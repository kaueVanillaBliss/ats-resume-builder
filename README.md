📄 ATS Resume Builder

**[PT-BR]**
Um sistema desenvolvido em **Python** e **Django** focado na criação de currículos otimizados para **Sistemas de Rastreamento de Candidatos (ATS)**. 

O objetivo é resolver o problema de currículos rejeitados por formatação incorreta, garantindo que o arquivo PDF gerado tenha uma estrutura limpa e legível para máquinas, aumentando as chances do candidato.

**Principais Funcionalidades:**
* **Modelagem Relacional Complexa:** Estrutura de banco de dados robusta (1:N) para gerenciar Experiências, Formações, Idiomas e Certificações.
* **Geração de PDF:** Conversão de templates HTML para arquivos PDF binários (utilizando WeasyPrint).
* **Padronização:** Interface que força a entrada estruturada de dados.

---

**[EN]**
A web system built with **Python** and **Django** focused on creating resumes optimized for **Applicant Tracking Systems (ATS)**.

The goal is to solve the issue of resumes being rejected due to poor formatting, ensuring the generated PDF file has a clean and machine-readable structure, increasing the candidate's chances.

**Key Features:**
* **Complex Relational Modeling:** Robust database structure (1:N) to manage Experience, Education, Languages, and Certifications.
* **PDF Generation:** HTML template conversion to binary PDF files (using WeasyPrint).
* **Standardization:** Interface that enforces structured data entry.

## 🛠 Tech Stack
* Python 3.x
* Django 5.x
* SQLite / PostgreSQL
* HTML5 / CSS3
* WeasyPrint (PDF Engine)
